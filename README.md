# SDCMUN'27 Official Website

A static multi-page conference website for Siridhamma College Model United Nations.

## Deploy with Cloudflare Pages

1. Upload the contents of this folder to the root of your GitHub repository.
2. In Cloudflare, open Workers & Pages and create a Pages project connected to that repository.
3. Use `main` as the production branch.
4. For a plain static HTML site, leave the build command blank.
5. Set the build output directory to `/` (or the repository root, depending on the Cloudflare setup).
6. Deploy.

The site uses static HTML, CSS and JavaScript. No package installation or build command is required.

## Before publishing
Replace placeholders with confirmed conference details, committee agendas, dais names and portraits, study guide PDFs, official contact details and approved social links. The Secretary-General message is an editable draft and should be reviewed and approved before publication.

The logo file is in `assets/sdcmun-logo.png`.
