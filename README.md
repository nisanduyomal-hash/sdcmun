# Conference website

A responsive multi-page conference website. Upload the contents of this folder to the existing Cloudflare Worker/static site deployment.

## Pages
- Home (`index.html`)
- About (`about.html`)
- Secretariat (`secretariat.html`)
- Committees (`committees.html`)
- Individual committee profile (`committee.html?c=unsc`, etc.)
- Conference (`conference.html`)
- Gallery (`gallery.html`)
- Contact (`contact.html`)

## Visual direction
An editorial, cinematic visual system using deep forest tones, muted brass, ivory typography, atmospheric landscape photography, restrained borders and responsive layouts. The design avoids repeating theme labels in the page copy.

## Deployment
Keep the folder structure intact and deploy all HTML files plus the `assets` folder. The site uses Google Fonts and remote Unsplash landscape photographs, so those visuals require an internet connection. Replace the landscape backgrounds with properly licensed/approved film stills if you have permission to use them.
